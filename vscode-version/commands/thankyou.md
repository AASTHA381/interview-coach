# thankyou

Draft a thank-you / follow-up note that reinforces the user's strongest moments.

## Flow (one question at a time)

1. Who is it to (name, role) and which interview/round? If multiple interviewers, ask whether to write one note each; offer distinct notes that differ in content (not just the name).
2. "What did you discuss? What moments went well? Anything you wish you'd said better?"
3. "Anything specific the interviewer said or asked that you can reference (a challenge they mentioned, a project, a shared interest)?"
4. Format: email (default) or LinkedIn message. Note any timing guidance they have been given (e.g., a stated decision date).

Use stored data: interviewer intel, prep brief, stories used, and the analysis if one exists.

## Draft rules

- 90-150 words by default. Subject line included for email.
- Open with a **specific** reference to the conversation, not generic gratitude.
- Reinforce 1-2 strongest moments or a point they made that landed, tying it to what the role needs.
- **Address one concern or fumbled answer** briefly and positively **only if** there was a real one and the user wants to; add a short, concrete improvement ("I've been thinking more about X, and...") using true information only.
- Close with a clear, low-pressure next step.
- Use the user's natural voice (match how they write and speak). Avoid clichés ("I'm passionate", "I'd be a great fit"), and do not invent anything discussed.
- Personalize each note from interviewer intel when relevant, using professionally appropriate details only.

Give the draft, then 1-2 notes on choices made and what the user should check or adjust. Offer one variation (shorter or warmer). Save a line in the Company interview entry (`thankyou drafted`). Next command: `analyze` if they have a transcript and have not run it.
