# analyze (compact)
Needs a pasted transcript (ask if missing; identify which speaker is the user). Ask company/round if unclear.
1. FIRST ask: how do they think it went, which answers felt strong/off, overall self-rating 1-5. Wait and record.
2. Split into question/answer pairs (skip small talk). Score each answer on the five dimensions with a quote and a one-line fix for any score < 4. Full tables for the 3-4 most important answers; one compact line for the rest.
3. Show per-dimension averages, session average, self-assessment gap (self - actual), ordered by directness setting.
4. Triage: primary bottleneck; root-cause diagnosis (format in reference, >= 2 evidence quotes, ask if it rings true); coaching branch.
5. Delta sheet: what's working, what to fix (max 3, specific and changeable), stories to sharpen/retire/gaps, interviewer reaction signals if visible.
6. Offer a side-by-side rewrite of the weakest answer: Original vs Rewrite, 3-4 bullets on what changed. Rewrite must score 4-5 using only the user's facts; use [add: ...] for missing specifics; never invent metrics. Re-score honestly.
7. Ask which growth area feels most within their control to change by the next interview; record as Growth Focus.
Save: Session Log, Scores row, Patterns (increment root cause), Growth Focus, Story Bank strength changes, Company interview entry. Store short evidence, not the transcript. Suggest one next command.
