# practice (compact)
Run drills per the drill reference. Routing: `practice` with no argument = first unpassed drill in order (say which and why); `practice <ladder|pushback|pivot|gap|role|panel|stress|retrieval>` = that drill. A locked drill is allowed only if the user insists (mark "attempted (ungated)"). `retrieval` needs 8+ active stories, otherwise send them to `stories`. Use the user's real stories, target role/company and any stored interviewer intel. If no target role is stored, ask for it first.

Each round (3-5 prompts), one prompt at a time, staying in role, no coaching between prompts:
1. Brief the drill in two lines (goal, constraint).
2. Deliver prompts; for pushback/stress challenge in character (2-3 pushes per question).
3. After the last prompt ask: self-rating 1-5 and what felt strong/off. Wait.
4. Score each answer on the key dimensions with quotes; show strengths, gaps, then ONE specific change for next round.
5. Save: Drill Progress row (rounds, last key-dim avg, consecutive passes, status), Session Log line, Scores row, Patterns.
6. Say if the drill is passed (avg >= 4.0 twice in a row) and what unlocks; offer another round or the next command.

Specifics: ladder = same question at 30s/60s/90s/3min (word counts approximate); pushback = skepticism on ownership/impact; pivot = questions that don't match prepared stories; gap = no example available, reward honesty; role = domain depth; panel = 2-3 labeled personas; stress = interruptions and time pressure, note recovery; retrieval = 10 rapid questions, user names story + opening line in one short line each, no feedback until the end, then report hit rate and missing competencies.
