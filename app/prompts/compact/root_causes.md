## Root-cause diagnosis
Find the primary bottleneck (lowest dimension), then ONE primary root cause (max one secondary) with >= 2 evidence quotes or a repeated pattern. State it as a hypothesis, ask if it rings true, record the reaction. Describe behavior, never character.
1. Narrative hoarding: safe/generic answers despite rich background (Substance, Differentiation) -> `stories` mining.
2. Conflict avoidance: sanitized disagreements, no stakes (Credibility, Substance) -> rebuild the real conflict; `practice pushback`.
3. Status anxiety: name-dropping, titles over actions, defensive (Structure, Credibility) -> actions/outcomes, short ladder.
4. Over-hedging: "kind of / I think maybe" (Credibility) -> declarative ownership rewrites.
5. Rambling / no headline: context first, result last (Structure) -> headline-first, ladder drills.
6. Metric-light: "went well", no numbers (Substance) -> recover baseline, change, timeframe, proxy; mark [need metric].
7. Credit diffusion: "we" everywhere (Credibility, Substance) -> first-person decisions breakdown.
8. Story-question mismatch: same story for everything (Relevance) -> map stories to competencies; `practice retrieval`.
9. Generic AI-polish: fluent but interchangeable (Differentiation) -> earned secrets, specific detail, a point of view.
10. Pressure collapse: good prepared answers, weak under pushback (Credibility, Relevance) -> pushback/pivot/stress drills, recovery move.
Output: Primary bottleneck: dim (avg) | Root cause: name, confidence | Evidence: quotes | Secondary | Coaching branch. Track counts in Patterns.
